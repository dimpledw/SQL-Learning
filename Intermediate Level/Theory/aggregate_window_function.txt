----------------------------
AGGREGATE WINDOW FUNCTION
----------------------------

AVERAGE
avg(sales) over (partition by product)   -- Returns the average value in a window
expression is required (Only Numeric values)
partiton by is optional 
order by is optional

-- Coalesce replaces null with specified value

COUNT 
count(*) over (partition by Product)  -- Returns the number of Rows in a window
expression is required (ALL Data types)  
partiton by is optional 
order by is optional

Find the total number of orders for each product

select count(orderID), product from sales group by product

select orderID, product, count(orderID) over (partition by product) from sales 

count(*) will count all the rows in a table, regardless of whether any value is NULL
count(1) is equals to count(*)
count(column) will count all Non Null values

Use Case of count
1. Overall Analysis
2. Category Analysis
3. Quality Checks - identify Nulls
4. Quality Checks - Identify Duplicates

-- Analytical Use case
Running and Rolling Total
They aggregate sequence of members, and the aggregation is updated each time a new member is added. 
This is called analysis over time.

Running Total - It will aggregate all values from the beginning up to the current point without
dropping off older data.

Rolling/Shifting Total
Aggregate all values within a fixed time window (e.g 30 days)
As new data is added, the oldest data point will be dropped.
